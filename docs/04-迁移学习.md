# 04 · 迁移学习：小数据分类的最优解

> 小数据量（几百到几千张）图像分类，**迁移学习是公认的最优解**。
> 本章讲清为什么、怎么做，以及本项目从 69% 到 89.5% 的实战。

## 动机

我们遇到真实瓶颈：猫狗二分类只有 1697 张训练图，从零训练的 CNN
要么过拟合（PyTorch 69%）、要么学不动（MiniTorch 50%）。怎么办？
**用别人在大数据上学到的特征**——这就是迁移学习。

## 1. 为什么迁移学习在小数据上有效

ImageNet 有 1400 万张图，预训练模型（ResNet18）已经学会了通用的视觉特征：
边缘、纹理、形状、物体部分。这些特征**对猫狗也适用**（猫和狗都有边缘、
皮毛纹理）。

**关键直觉**：与其从零学"什么是猫"，不如用"已经懂边缘/纹理的模型"，
只需教它"怎么组合这些特征区分猫狗"。

## 2. 三种做法（按推荐排序）

### 路径A：frozen 特征提取（最稳）
```python
model = models.resnet18(weights=IMAGENET1K_V1)
for param in model.parameters():
    param.requires_grad = False    # 冻结全部
model.fc = nn.Linear(512, 2)       # 只换头部
# 优化器只喂 model.fc.parameters()
```
预期：蚂蚁/蜜蜂 244 张官方教程达 **95.4%**；本项目 78%。

### 路径B：微调后几层（本项目采用，最优）
```python
# 冻结全部，再解冻最后 2 个 block
for param in model.layer4.parameters():
    param.requires_grad = True
model.fc = nn.Linear(512, 2)
```
让最接近输出的层（最任务相关）也学习。本项目 **89.5%**。

### 路径C：全量微调（小数据风险高）
直接全量微调极易过拟合，不推荐小数据用。

## 3. 判别性学习率（fastai 核心技巧）

不同层用不同学习率：
- **backbone**（微调层）：低 lr（1e-4）——别破坏预训练特征
- **头部**（新层）：高 lr（1e-3）——快速学习新任务

```python
params = [
    {"params": backbone_params, "lr": 1e-4},
    {"params": head_params,    "lr": 1e-3},
]
optimizer = torch.optim.Adam(params)
```

**为什么**：backbone 已经很好，微调只需"轻微调整"；头部从零学，需要大步。

## 4. 数据增强（小数据必备）

训练时对图做随机变换，等价于"免费增加数据"：

```python
train_tf = transforms.Compose([
    transforms.Resize(80),
    transforms.RandomResizedCrop(64, scale=(0.8, 1.0)),  # 随机缩放
    transforms.RandomHorizontalFlip(),                    # 翻转
    transforms.RandomRotation(degrees=15),                # 旋转
    transforms.ColorJitter(brightness=0.2, contrast=0.2,
                           saturation=0.2, hue=0.1),      # 颜色
    transforms.ToTensor(),
    transforms.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),
])
```

**关键规则**（研究结论）：
- 增强要**适度**，别堆太猛（过度增强反而降效果）
- 验证集**绝不做增强**（否则指标失真）
- 基础增强（翻转/裁剪/旋转）对小数据通常优于高级增强（MixUp）

## 5. Early stopping：防过拟合的最后防线

```python
if val_loss < best_loss:
    best_loss = val_loss
    best_weights = copy.deepcopy(model.state_dict())
    trigger = 0
else:
    trigger += 1
    if trigger >= patience:   # patience=8
        break                  # 连续 8 轮没提升就停
```

保存最优权重，不保留最后的（可能已过拟合）。

## 6. 本项目实战结果

| 方案 | val acc | 分析 |
|---|---|---|
| 从零 CNN | 0.692 | 过拟合（train 1.0, val 0.69）|
| frozen ResNet18 | 0.779 | 欠拟合（特征没充分用）|
| **微调 + 判别性 lr** | **0.895** | 最优（train 0.96, val 0.90）|

**关键洞察**：不是模型越大越好，而是"用对方法"。
微调后几层 + 判别性 lr + 适度增强 + early stopping = 小数据分类黄金组合。

## 7. MiniTorch 手写框架怎么办

MiniTorch 没有预训练模型可用（那是 PyTorch 生态的优势），只能从零训练。
它验证的是"原理"（手写反向传播/卷积/BN），效果上限受限于数据量。
**这恰恰说明了迁移学习/框架生态的价值**——这是教学对比的意义。

## 小结

- 迁移学习 = 用预训练特征 + 学新任务，小数据最优解
- 微调后几层 > frozen > 全量微调（小数据）
- 判别性学习率：backbone 低、头部高
- 适度增强 + early stopping 是标配
- 本项目：从 69% → 89.5%
