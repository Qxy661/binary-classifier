# 01 · 二分类原理

> 二分类是分类任务的基础：判断"是 A 还是 B"。奶龙/塔菲、猫/狗，都是二分类。
> 本章讲清二分类的数学——从 CIFAR-10 的 10 类到二分类，发生了什么变化。

## 动机

M1 和 MiniTorch 做的是 **10 类**分类（CIFAR-10）。二分类看似更简单，
其实有一个**关键区别**：二分类可以用 **1 个 logit + sigmoid**，比 10 类 softmax 更简洁、也更符合直觉。

## 1. 从多分类到二分类

**多分类（10 类）**：
```
10 个 logits → softmax → 10 个概率（和为 1）
```

**二分类**：
```
1 个 logit z → sigmoid(z) → 概率 p (0~1)
类别 = p > 0.5 ? A : B
```

**为什么可以只用 1 个 logit？**
因为二分类只有两个类别，一个概率就够（另一个是 1-p）。
softmax 的两个输出 $[p, 1-p]$ 可以由一个值 $z$ 决定：$p = \sigma(z)$。

## 2. Sigmoid：把分数变成概率

*sigmoid* 函数把任意实数映射到 (0, 1)：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

```
z → -∞   p → 0    （很可能是类别 A）
z →  0   p → 0.5  （不确定）
z → +∞   p → 1    （很可能是类别 B）
```

**数值稳定性**：实现时用 `np.clip(z, -30, 30)` 防溢出。

## 3. 二分类的损失：Binary Cross-Entropy (BCE)

*二元交叉熵*（BCE）衡量预测概率和真实标签的差距：

$$L = -\frac{1}{N}\sum_i \left[ y_i \log p_i + (1-y_i)\log(1-p_i) \right]$$

其中 $y_i \in \{0, 1\}$，$p_i = \sigma(z_i)$。

**直觉**：
- 如果 $y=1$ 且 $p \rightarrow 1$：$-\log(1) = 0$，损失小（预测对）
- 如果 $y=1$ 且 $p \rightarrow 0$：$-\log(0) \rightarrow \infty$，损失大（预测错）

## 4. 著名的简化：d(loss)/d(z) = p - y

这是深度学习里最漂亮的简化之一。对 BCE + sigmoid 求梯度：

$$\frac{\partial L}{\partial z_i} = p_i - y_i$$

**推导**（关键）：
$$
p = \sigma(z), \quad \frac{dp}{dz} = p(1-p)
$$
$$
\frac{\partial L}{\partial z} = \frac{\partial L}{\partial p} \cdot \frac{dp}{dz}
= \left(-\frac{y}{p} + \frac{1-y}{1-p}\right) \cdot p(1-p)
= p - y
$$

**为什么重要**：softmax + cross-entropy 的梯度是 `softmax - one_hot`（M1 学过），
sigmoid + BCE 的梯度是 `p - y`——**都是"预测减真实"**，极其优雅。

这就是 `train_minitorch.py` 里 `bce_backward` 的实现：

```python
def bce_backward(logits, labels):
    p = sigmoid(logits)
    return (p - labels) / labels.size   # d(loss)/d(logits) = (p - y) / N
```

## 5. 完整训练循环（二分类版）

对比 CIFAR-10 的循环，**只有损失和反向不同**：

```python
# 前向：1 个 logit
logits = model.forward(x)                 # (N, 1)

# 损失：BCE
loss = bce_loss(logits, labels)

# 反向：从 d(loss)/d(logits) 开始
dlogits = bce_backward(logits, labels)    # = (p - y) / N
model.backward(dlogits)
```

**其余完全相同**：清梯度 → 前向 → 损失 → 反向 → 更新。

## 6. MiniTorch vs PyTorch 实现对比

| | MiniTorch | PyTorch |
|---|---|---|
| sigmoid | `sigmoid(z)` 手写 | `torch.sigmoid(z)` |
| 损失 | `bce_loss` 手写 | `nn.BCEWithLogitsLoss()` |
| 反向 | `bce_backward` 手写 | `loss.backward()` 自动 |

**关键认知**：PyTorch 的 `BCEWithLogitsLoss` 内部做的，就是我们手写的
sigmoid + BCE + `p - y` 梯度。API 封装了数学，原理完全一样。

## 小结

- 二分类 = 1 个 logit + sigmoid，比多分类简洁
- BCE 损失衡量预测与真实差距
- `d(loss)/d(z) = p - y` 是漂亮的简化
- 训练循环和多分类只有损失/反向不同
